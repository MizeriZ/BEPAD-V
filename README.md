# BEPAD-V

Launchpad를 사용하는 Unity 리듬 게임 프로젝트입니다.

## 프로젝트 열기

1. Git LFS를 설치하고 `git lfs install`을 실행합니다.
2. 저장소를 복제한 뒤 `git lfs pull`로 대용량 폰트 에셋을 받습니다.
3. Unity Hub에서 저장소 폴더를 추가하고 Unity **6000.4.1f1**로 엽니다.
4. `Assets/Scenes/Title.unity`에서 시작합니다.

Windows에서 Launchpad MK2 및 Launchpad X 입력을 사용합니다.

- [멀티플레이 설명](MULTIPLAY.md)
- [멀티플레이 UI 연결 가이드](MULTIPLAY_UI_SETUP.md)

`Assets`, `Packages`, `ProjectSettings`를 포함합니다. `Library`, 임시 파일,
로컬 백업 및 `Builds`의 실행 파일은 제외합니다. 두 대용량 SDF 폰트 에셋은 Git LFS로 관리합니다.
